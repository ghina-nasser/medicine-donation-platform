# medicine-donation-platform
A web-based platform for managing medicine donations.
A simple web-based platform developed as an academic project to manage medicine donations.

## Features
- User-friendly interface
- Add and manage donated medicines
- Store and retrieve data using browser localStorage
- Search and filter donated medicines

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was developed as part of my Computer Science studies to practice front-end web development and JavaScript functionality.
